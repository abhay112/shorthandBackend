## Overview

The batch-test management system provides admins with the following capabilities:

1. **Monitor Test Progress**: View how many students have attempted/completed a test for a specific batch
2. **Close Tests**: Disable test-taking for a batch (like "time's up" in real-world scenarios)
3. **Generate Rankings**: Manually trigger ranking calculation for a batch-test combination
4. **Control Visibility**: Students can only see rankings after they are generated by admin

### Key Concepts

- **Test Closure**: When a test is closed for a batch, students in that batch can no longer start new test sessions
- **Ranking Generation**: Rankings are calculated and stored only after admin explicitly generates them
- **Batch-Test Combination**: Each test can be managed independently per batch

## Admin APIs

All admin endpoints require:
- Authentication: `Authorization: Bearer <firebase-id-token>`
- Role: Admin user

Base path: `/api/v1/admin/tests`

### Close Test for Batch

Close a test for a specific batch, preventing students from starting new test sessions.

**Endpoint:** `POST /api/v1/admin/tests/:testId/batch/:batchId/close`

**Parameters:**
- `testId` (path, required): Test ID
- `batchId` (path, required): Batch ID

**Request Body:**
```json
{
  "reason": "Time's up - Test window closed" // Optional
}
```

**Response (200 OK):**
```json
{
  "success": true,
  "message": "Test closed for batch successfully",
  "data": {
    "test": {
      "_id": "64f1b2c3d4e5f6a7b8c9d0e1",
      "title": "Daily Practice Test",
      "closedForBatches": [
        {
          "batchId": {
            "_id": "64f1b2c3d4e5f6a7b8c9d0e2",
            "name": "Batch 2024-01"
          },
          "closedBy": {
            "_id": "64f1b2c3d4e5f6a7b8c9d0e6",
            "name": "Admin User"
          },
          "closedAt": "2024-01-15T17:00:00.000Z",
          "reason": "Time's up - Test window closed"
        }
      ]
    }
  }
}
```

**Error Responses:**
- `400 Bad Request`: Test is already closed for this batch
- `404 Not Found`: Test or batch not found

**Behavior:**
- Students cannot start new test sessions after closure
- Existing in-progress sessions can still be completed
- Test remains visible but shows "closed" status

### Open Test for Batch

Re-open a test for a batch, allowing students to start new test sessions again.

**Endpoint:** `POST /api/v1/admin/tests/:testId/batch/:batchId/open`

**Parameters:**
- `testId` (path, required): Test ID
- `batchId` (path, required): Batch ID

**Response (200 OK):**
```json
{
  "success": true,
  "message": "Test opened for batch successfully",
  "data": {
    "test": {
      "_id": "64f1b2c3d4e5f6a7b8c9d0e1",
      "title": "Daily Practice Test",
      "closedForBatches": []
    }
  }
}
```

**Error Responses:**
- `400 Bad Request`: Test is not closed for this batch
- `404 Not Found`: Test or batch not found

### Generate Rankings for Batch-Test

Manually trigger ranking calculation for a batch-test combination. Rankings are only visible to students after this endpoint is called.

**Endpoint:** `POST /api/v1/admin/tests/:testId/batch/:batchId/generate-ranks`

**Parameters:**
- `testId` (path, required): Test ID
- `batchId` (path, required): Batch ID

**Response (200 OK):**
```json
{
  "success": true,
  "message": "Rankings generated successfully for 18 students",
  "data": {
    "test": {
      "_id": "64f1b2c3d4e5f6a7b8c9d0e1",
      "title": "Daily Practice Test",
      "rankingsGenerated": [
        {
          "batchId": {
            "_id": "64f1b2c3d4e5f6a7b8c9d0e2",
            "name": "Batch 2024-01"
          },
          "generatedBy": {
            "_id": "64f1b2c3d4e5f6a7b8c9d0e6",
            "name": "Admin User"
          },
          "generatedAt": "2024-01-15T18:00:00.000Z"
        }
      ]
    },
    "rankingsGenerated": 18,
    "message": "Rankings generated successfully for 18 students"
  }
}
```

**Error Responses:**
- `400 Bad Request`: 
  - Rankings already generated for this batch-test
  - No completed results found
- `404 Not Found`: Test or batch not found

**What Happens:**
1. Fetches all completed results for the batch-test combination
2. Sorts by WPM, accuracy, and speed (descending)
3. Calculates rank and percentile for each student
4. Updates `StudentRanking` documents
5. Updates `Result` documents with rank/percentile
6. Marks rankings as generated in the test document

**Important Notes:**
- Only completed results are included in rankings
- Rankings are based on best attempt per student (if multiple attempts exist)
- Students cannot see rankings until this endpoint is called

## Student Behavior Changes

### Test Access

When a test is closed for a student's batch:

**Before Closure:**
- Student can start new test sessions
- Access check returns `canTake: true`

**After Closure:**
- Student cannot start new test sessions
- Access check returns:
  ```json
  {
    "canTake": false,
    "reason": "Test is closed for your batch. Time's up!"
  }
  ```
- Existing in-progress sessions can still be completed
- Test appears in current tests list but shows closed status

### Ranking Visibility

**Before Rankings Generated:**
- `GET /api/v1/user/rankings` returns empty array or filters out rankings
- `GET /api/v1/user/leaderboards/:batchId?testId=...` returns empty array
- Result details may not show rank/percentile

**After Rankings Generated:**
- Rankings become visible in all student endpoints
- Leaderboards show ranked students
- Result details include rank and percentile

## Frontend Integration Guide

### Admin Dashboard - Test Monitoring

**1. Statistics View**

```javascript
// Fetch statistics
const response = await fetch(
  `/api/v1/admin/tests/${testId}/batch/${batchId}/statistics`,
  {
    headers: {
      'Authorization': `Bearer ${token}`
    }
  }
);

const { data } = await response.json();

// Display:
// - Total students: data.statistics.totalStudents
// - Attempted: data.statistics.attemptedCount
// - Completed: data.statistics.completedCount
// - Not attempted: data.statistics.notAttemptedCount
// - Lists: data.attemptedStudents, data.completedStudents, data.notAttemptedStudents
```

**2. Close Test Button**

```javascript
// Close test
const response = await fetch(
  `/api/v1/admin/tests/${testId}/batch/${batchId}/close`,
  {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      reason: 'Time\'s up - Test window closed'
    })
  }
);
```

**3. Generate Rankings Button**

```javascript
// Generate rankings
const response = await fetch(
  `/api/v1/admin/tests/${testId}/batch/${batchId}/generate-ranks`,
  {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`
    }
  }
);

const { data } = await response.json();
// Show success message: `Rankings generated for ${data.rankingsGenerated} students`
```

## Example Workflows

### Workflow 1: Daily Test Management

1. **Morning**: Admin assigns test to Batch 1
2. **During Day**: Students take the test
3. **Afternoon**: Admin checks statistics:
   ```bash
   GET /api/v1/admin/tests/{testId}/batch/{batchId}/statistics
   ```
4. **Evening**: Admin closes test:
   ```bash
   POST /api/v1/admin/tests/{testId}/batch/{batchId}/close
   ```
5. **Next Day**: Admin generates rankings:
   ```bash
   POST /api/v1/admin/tests/{testId}/batch/{batchId}/generate-ranks
   ```
6. **Students**: Can now see their rankings

### Workflow 2: Assessment Test

1. **Week 1**: Admin creates assessment test
2. **Week 1-2**: Students take test (multiple attempts allowed)
3. **Week 2 End**: Admin closes test for all batches
4. **Week 3**: Admin reviews all results
5. **Week 3**: Admin generates final rankings
6. **Week 3+**: Students see final rankings

### Workflow 3: Re-opening Test

1. Test was closed for Batch 1
2. Admin realizes some students need more time
3. Admin re-opens test:
   ```bash
   POST /api/v1/admin/tests/{testId}/batch/{batchId}/open
   ```
4. Students can now take the test again
5. Admin closes again when ready
6. Admin generates rankings

## Error Handling

### Common Errors

**400 Bad Request:**
- Test already closed for batch
- Rankings already generated
- No completed results found

**403 Forbidden:**
- User is not an admin
- Student trying to access admin endpoints

**404 Not Found:**
- Test ID invalid
- Batch ID invalid
- Test or batch doesn't exist

### Error Response Format

```json
{
  "success": false,
  "message": "Error message here",
  "error": {
    "code": "ERROR_CODE",
    "details": {}
  }
}
```

## Best Practices

1. **Check Statistics Before Closing**: Always review statistics to ensure most students have completed
2. **Generate Rankings After Closure**: Generate rankings only after test is closed to ensure final results
3. **Communicate with Students**: Inform students when tests will be closed
4. **Monitor Completion Rates**: Use statistics endpoint to track participation
5. **Batch-Specific Management**: Remember that each batch-test combination is managed independently
